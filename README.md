# Landing Page

صفحة هبوط ثابتة جاهزة للنشر على GitHub Pages.

- `index.html` — الصفحة
- `hero.png` — الصورة المستخدمة في التصميم

ملاحظة: النموذج الحالي لا يجمع كلمات مرور ولا يرسل بيانات إلى خادم؛ زر المتابعة يعرض رسالة نجاح فقط. لإضافة جمع Leads بشكل مشروع، اربط النموذج بخدمة Forms/CRM مع توضيح الغرض للمستخدم.
