# Interface Demo

Maquette visuelle inspirée d'une interface de connexion mobile.

- La bannière `hero.png` est affichée en haut, avec une taille raisonnable.
- Les champs sont uniquement visuels : aucune donnée n'est saisie, envoyée ou enregistrée.
- Le bouton affiche un message de démonstration.
- Cette interface n'est pas une page officielle de Facebook ou Messenger.
